# Отпуск сентябрь — октябрь 2026

Разбор вариантов трёхнедельного отпуска для семьи из трёх человек (двое взрослых + ребёнок 1 год 8 месяцев).

**Сайт:** https://abagnale026.github.io/trip-sept-2026/

## Жёсткие условия

- Вылет в окне **11–15 сентября 2026**, поездка ~3 недели
- **Строго прямые рейсы** на каждом сегменте
- **Без Москвы** — даже транзитом
- Вылет из **Перми**, максимум из **Екатеринбурга**
- **Последняя страна — Армения**: жена с ребёнком улетают прямым из Еревана, муж остаётся
- 2–3 страны по 6–8 дней
- Бюджет 400–800 тыс ₽ на троих
- Загранпаспорт ребёнка: обычный, 5 лет, без чипа
- **ОАЭ и Катар исключены** — сентябрьская жара +34…40 °C

## Ключевые ограничения

Узкое место маршрута — не Стамбул, а **вход в Ереван**. Звартноц принимает прямые из 83 аэропортов, но после отсева по визам, климату и медицине остаются только **Стамбул, Тбилиси, Ташкент и Астана**.

- **Из Перми в сентябре нет прямых в Дубай и Стамбул**
- **Анталья → Ереван прямых не существует** — только через Стамбул как отдельную остановку
- **Баку, Батуми, Алматы, Каир → Ереван** прямых рейсов нет
- **Стамбул → Ереван днём летает только по понедельникам** (Turkish TK-1158, 13:40 → 16:50). Остальные рейсы в 02:40, 21:45 и 23:35
- **Тбилиси → Ереван** — самый удобный вход: 08:20 → 08:50, 30 минут, пн/ср/пт
- **Ереван → Пермь только ср и вс** (Shirak Avia), сезон до ~25 октября → дата возврата: **4, 7 или 11 октября**
- Air Arabia Екатеринбург — Шарджа: зимний рейс, в сентябре не летает

## Что даёт стамбульский хаб

Из всей сети Стамбула в маршрут проходят ровно два направления с прямым рейсом в Ереван — **Тбилиси** (до 8 рейсов в день) и **Ташкент**. Всё остальное либо не стыкуется с Ереваном, либо отпадает по визам и климату.
